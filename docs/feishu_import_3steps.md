## 方案 A：飞书电子表格（推荐，最简单）

和 Excel 一样用，底部点标签切换三个表，**不需要学多维表格**。

1. 打开 **飞书** → 左侧 **云文档**
2. 点右上角 **「+」** → **上传** → 选择  
   `学练机发版用户声音闭环.xlsx`（在「下载」文件夹里）
3. 上传完成后 **双击打开**，底部可看到三个 Sheet

**怎么用：**

| 工作表 | 你要做的事 |
|--------|------------|
| 发版项台账 | 看「用户可感知」列，改掉不认同的 |
| 用户原声关联 | 看「匹配分」高的行，把「关联已确认」改成「是」 |
| 触达清单 | 有 userId 的用户，填触达状态和话术 |

汇报时：复制三个表里的统计到飞书文档即可。

## 方案 B：自动创建「多维表格」（需一次性配置，我来跑脚本）

如果你坚持要用多维表格，需要飞书开放平台凭证（约 5 分钟）：

### 1. 创建应用

1. 打开 https://open.feishu.cn/app → **创建企业自建应用**
2. 名称随意，如「发版看板同步」
3. **权限管理** 里搜索并开通：
   - `创建多维表格` (base:app:create)
   - `查看、评论、编辑和管理多维表格` (bitable:app)
4. **版本管理与发布** → 创建版本 → 申请发布（企业内一般自动通过）
5. 飞书 **工作台** 里搜索应用名 → **安装**

### 2. 把凭证给我（或自己写入）

在应用 **凭证与基础信息** 页复制 App ID、App Secret，写入：

```bash
mkdir -p .config/tokens
cat > .config/tokens/feishu.json << 'EOF'
{
  "app_id": "cli_xxxxxxxx",
  "app_secret": "xxxxxxxxxxxxxxxx"
}
EOF
chmod 600 .config/tokens/feishu.json
```

把 `app_id` / `app_secret` 发我（或你自己执行下面命令）。

### 3. 一键创建

```bash
cd /Users/zhouziwei/FeedBackChecking
python3 scripts/export_feishu_voice_closure.py
python3 scripts/create_feishu_bitable.py
```

成功后会打印 **飞书多维表格链接**，三张表和数据都会建好。
