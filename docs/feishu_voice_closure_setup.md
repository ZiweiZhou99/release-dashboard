# 飞书 · 发版用户声音闭环 搭建说明

> 三个交付物：**发版项台账**、**用户原声关联**、**触达清单**（+ 汇报用飞书文档视图）  
> 本地已生成可导入 CSV：`exports/feishu/`

---

## 一、飞书空间结构（推荐）

新建多维表格 Base：**学练机 · 发版用户声音闭环**

| 数据表 | 对应文档 | 用途 |
|--------|----------|------|
| **1_发版项台账** | 工作底稿 | 近半年发版项 + 你是否确认「用户可感知」 |
| **2_用户原声关联** | 关联台账 | 发版项 ↔ 工单/反馈，人工确认关联 |
| **3_触达清单** | 执行清单 | 要通知的用户、话术、触达状态 |

另建一篇 **飞书文档**（非表格）：**发版用户声音汇报**，用关联表的统计 + 典型案例拼周报/月报。

---

## 二、建表步骤

### 1）导入三张表

1. 飞书多维表格 → 新建 → 从 CSV 导入  
2. 依次导入 `exports/feishu/` 下三个文件（UTF-8，含 BOM）  
3. 表名改为：`发版项台账`、`用户原声关联`、`触达清单`

### 2）表 1：发版项台账 — 字段说明

| 字段 | 类型建议 | 说明 |
|------|----------|------|
| 发版项ID | 文本（主键） | `版本::名称`，勿改 |
| 版本号 | 文本 | |
| 发版日期 | 日期 | |
| 机型 | 文本 | |
| 发版项名称 | 文本 | |
| 来源 | 单选 | Confluence / 石墨 |
| 自动初筛 | 单选 | 建议可感知 / 待确认 / 建议内部 |
| **用户可感知** | 单选 | **是 / 否 / 待确认** ← 你已确认的主字段 |
| 用户价值一句话 | 文本 | PM 补：用户能感知到什么 |
| 关联原声数 | 数字 | 可由关联表 rollup |
| 备注 | 文本 | |

**视图建议**

- `用户可感知`：筛选「用户可感知 = 是」  
- `按版本`：按版本号分组  

### 3）表 2：用户原声关联 — 字段说明

| 字段 | 类型建议 | 说明 |
|------|----------|------|
| 关联ID | 文本（主键） | |
| 发版项ID | **关联** → 表1 | 双向关联 |
| 版本号 / 发版项名称 | 查找引用 | 从表1带出 |
| 原声ID | 文本 | |
| 原声来源 | 单选 | 工单 / 用户反馈 |
| 用户ID | 文本 | 反馈有，工单常无 |
| 设备 / 原声时间 / 原声摘要 | 文本 | |
| 原声链接 | URL | |
| 匹配分 | 数字 | 自动召回参考，非最终依据 |
| 匹配关键词 | 文本 | |
| **关联类型** | 单选 | Bug修复 / 体验优化 / 建议落地 / 不关联 |
| **关联已确认** | 单选 | 是 / 否 |
| **需要触达** | 单选 | 是 / 否 / 待判断 |
| 触达状态 | 单选 | 未触达 / 已通知 / 无需触达 |
| 触达话术 / 触达人 / 触达时间 | 文本、人员、日期 | |
| 备注 | 文本 | |

**你的工作流**

1. 打开「匹配分」较高的行，读原声摘要  
2. 确认后：`关联已确认 = 是`，填 `关联类型`  
3. 若需通知用户：`需要触达 = 是`（通常仅有 userId 的反馈）

### 4）表 3：触达清单

两种方式二选一：

- **方式 A（推荐）**：表 2 建视图「触达清单」，筛选  
  `关联已确认=是` 且 `需要触达=是`  
- **方式 B**：导入 `3_触达清单候选.csv`，与表 2 同步维护  

字段：用户ID、发版项、原声摘要、触达状态、话术、触达人、触达时间。

## 三、汇报文档（飞书 Doc 模板）

每版本或每周复制下面结构到飞书文档：

```markdown
# 学练机 vX.XX · 用户声音回应摘要（YYYY-MM-DD）

## 1. 本期概览
- 用户可感知发版项：{表1 筛选「是」计数}
- 已关联用户原声：{表2 关联已确认=是}
- 计划触达 / 已触达：{表3 统计}

## 2. 重点回应（按主题 2~4 条）
### 主题名
- 发版项：……
- 代表原声：……（附链接）
- 用户价值：……

## 3. 典型案例（1~3 个）
| 用户原声 | 发版回应 | 触达状态 |

## 4. 听见但未覆盖（诚实写）
- ……

## 5. 下版本关注
- ……
```

数字可从多维表格 **仪表盘** 或字段统计填入。

## 四、本地数据如何更新

```bash
# 重新生成发版确认清单（发版有更新时）
python3 scripts/generate_release_perception_review.py --months 6

# 导出飞书 CSV（含关键词召回候选关联）
python3 scripts/export_feishu_voice_closure.py
```

默认规则：`🟢建议可感知→是`，`⚪建议内部→否`，`🟡待确认→待确认`。  
若你在飞书里改了「用户可感知」，以飞书为准；下次导出会覆盖 CSV，**不要直接重导覆盖已人工确认的关联表**，只增量导入新发版项。
